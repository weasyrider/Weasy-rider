# Weasy Rider — site Astro

Site vitrine statique construit avec Astro. L’accueil reprend la maquette fournie. Les pages Nos produits, Compatibilité, Installation, À propos, FAQ et Contact sont prêtes à être complétées. Une page provisoire est prévue pour le lien italien.

## Démarrer en local

```sh
npm install
npm run dev
```

## Construire

```sh
npm run build
```

Le site généré se trouve dans `dist/`. Pour le déploiement depuis GitHub, configurez dans Sevalla la commande de build `npm run build` et le répertoire de sortie `dist` (ou suivez le mode de déploiement de votre application Sevalla).

Les images fournies et les déclinaisons recadrées pour l’accueil sont dans `public/images/`.
