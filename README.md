# Bonjour — projet Astro

Un site Astro minimal qui affiche « Bonjour » et un logo de remplacement.

## Personnaliser le logo

Remplacez `public/logo.svg` par votre logo. Si votre fichier est en PNG ou JPG, déposez-le dans `public/`, puis modifiez `src/pages/index.astro` pour utiliser son nom (par exemple `/logo.png`).

## Démarrer en local

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Le site statique généré se trouve dans `dist/`.
